🥤 Gestion des stocks

Chaque achat enregistre automatiquement une dépense réelle dans la caisse. Le coût unitaire = prix du pack ÷ nombre de canettes. Les consommations des collègues sont déduites du stock global (tous types confondus), sauf si tu les répartis par type dans l’inventaire.
