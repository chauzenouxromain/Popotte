POPOTTE V3 — Reports automatiques des crédits et impayés.

1. Sauvegardez votre caisse JSON depuis POPOTTE V2.
2. Remplacez uniquement index.html dans votre dépôt GitHub Pages.
3. Les données existantes restent sous la même clé locale popotte_v1.
4. Le report se calcule depuis le mois d’inscription des nouveaux collègues ; pour les collègues déjà présents, depuis leur première activité connue (sinon depuis le mois actuel).
5. Les anciens mois ne sont pas verrouillés : une correction recalculera les soldes suivants.
6. Les données restent propres au navigateur/appareil.
